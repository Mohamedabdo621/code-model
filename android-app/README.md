# NEXA Code 2100 — تطبيق أندرويد لمصمم الأكواد (الإصدار 2: نموذج محلي)

تطبيق أندرويد (APK) فيه نموذج الكود المدرّب بتاع Alex
(`darklink56/qwen-coder-1.5b-lora-out`) **شغال جوه التطبيق نفسه** بمحرك
llama.cpp — من غير سيرفر، من غير رابط، ومن غير إنترنت بعد أول تنزيل.

- **💬 اسأل**: شات مع النموذج المحلي — يرد على طول من الجهاز.
- **🛠️ ابنِ**: اوصف مشروع ويب، والنموذج يخطط ملفاته ويبنيه على الجهاز
  (HTML/CSS/JS...) مع سجل بناء مباشر.
- **📁 مشاريعي**: المشاريع المبنية محفوظة على الجهاز — معاينة فورية
  من جوه التطبيق (WebView)، وحذف بضغطة.
- **🧠 النموذج**: إدارة النموذج المحلي — تنزيل (مرة واحدة، ~950MB من
  Hugging Face)، تحميل في الذاكرة، حذف.

التصميم: ثيم "سنة 2100" — خلفية سائلة متحركة (كتل نيون بتتحرك زي المية)،
بطاقات زجاجية، وأزرار بتدرج سماوي ← بنفسجي ← وردي.

## قبل أول استخدام (مرة واحدة)

النموذج لازم يتحوّل لصيغة GGUF الأول: شغّل
`notebooks/convert_gguf_colab.ipynb` في Colab (دمج + تحويل + ضغط
Q4_K_M + رفع إلى `darklink56/qwen-coder-1.5b-gguf`). بعدها التطبيق
هينزّل الملف لوحده من تبويب «النموذج».

## البناء من المصدر (من غير Gradle)

المطلوب: JDK 17 + Android SDK (platform 34 + build-tools 34) +
Android NDK r27 + ‏llama.cpp مضمّن في `jni/llama.cpp` (إصدار b6500).

```bash
git clone --depth 1 --branch b6500 https://github.com/ggml-org/llama.cpp jni/llama.cpp
python3 gen_icons.py   # أيقونات mipmap (مرة واحدة)
./build.sh             # مكتبات أصلية (arm64-v8a) + APK
```

الناتج: `NEXA-Code-2100.apk` موقّع بمفتاح debug — للتثبيت الشخصي
(sideload)، مش للنشر على Play Store.

- الحزمة: `com.alex.nexacode` — أندرويد 7+ (minSdk 24)
- الكود: Java على Android framework + ‏JNI/llama.cpp (C++)،
  من غير أي مكتبات جافا خارجية.
- ملحوظة: ملف `modal_app.py` ونوتبوك التشغيل السحابي لسه موجودين
  كبدائل اختيارية لو بقى فيه وسيلة دفع متاحة لاحقاً.
