# NEXA Code 2100 — تطبيق أندرويد لمصمم الأكواد

تطبيق أندرويد (APK) بيخلي نموذج الكود المدرّب بتاع Alex
(`darklink56/qwen-coder-1.5b-lora-out`) مصمم أكواد في جيبه:

- **💬 اسأل**: شات مع النموذج — اطلب أي كود ويرد عليك.
- **🛠️ ابنِ**: اوصف مشروع ويب، والنموذج يخطط ملفاته ويبنيه فعلياً على
  الجهاز (HTML/CSS/JS...) مع سجل بناء مباشر.
- **📁 مشاريعي**: المشاريع المبنية محفوظة على الجهاز — معاينة فورية
  لأي مشروع من جوه التطبيق (WebView)، وحذف بضغطة.
- **⚙️ الرابط**: تعديل رابط الـ API (gradio.live) لما جلسة Colab تتجدد.

التصميم: ثيم "سنة 2100" — خلفية سائلة متحركة (كتل نيون بتتحرك زي المية)،
بطاقات زجاجية، وأزرار بتدرج سماوي ← بنفسجي ← وردي.

## التشغيل

1. شغّل `notebooks/serve_api_colab.ipynb` في Colab (T4) وخد رابط
   gradio.live الجديد.
2. ثبّت الـ APK على الموبايل (تثبيت من مصادر خارجية مسموح بيه لملفك).
3. لو الرابط اتغير: افتح تبويب «الرابط» في التطبيق والصق الجديد واحفظ.

## البناء من المصدر (من غير Gradle)

المطلوب: JDK 17 + Android SDK (platform 34 + build-tools 34).

```bash
python3 gen_icons.py   # يولّد أيقونات mipmap (مرة واحدة)
./build.sh             # aapt2 + javac + d8 + zipalign + apksigner
```

الناتج: `NEXA-Code-2100.apk` موقّع بمفتاح debug — مناسب للتثبيت الشخصي
(sideload)، مش للنشر على Play Store.

- الحزمة: `com.alex.nexacode` — أندرويد 7+ (minSdk 24)
- الكود: Java خام على Android framework من غير أي مكتبات خارجية.
